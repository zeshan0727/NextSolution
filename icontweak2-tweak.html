IconTweak2 1.0.2: Swipe Home Screen Icons for a Control Menu

IconTweak2 version 1.0.2 is a Home Screen tweak by ichitaso. Its package description says that users can swipe icons to show a control menu and more. This release is listed for the iphoneos-arm and iphoneos-arm64 architectures and has dependencies on firmware version 15.0 or newer, MobileSubstrate, and PreferenceLoader.
