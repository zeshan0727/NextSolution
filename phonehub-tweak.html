Phonehub 1.1.3: Caller ID, Auto Redial, and Phone App Features

Phonehub 1.1.3 is a package in the Messages & Phone category. Its description lists Caller ID lookup through Truecaller, GetContact, NumberBook, and Kuwait; keypad and live-call lookup controls; Auto Redial for busy and no-answer or unreachable calls; proximity-driven Smart Loudspeaker audio routing; a dual-SIM picker; local lookup caching; recent-call chat shortcuts; Phone app interface refinements; and localization in nine languages. The package variant is listed for iphoneos-arm64 and declares dependencies on MobileSubstrate, firmware (>= 15.0), and PreferenceLoader.

What the package metadata says it does

  • Lists Caller ID lookup through Truecaller, GetContact, NumberBook, and Kuwait.
  • Adds a Caller ID button to the keypad for looking up an entered number; in Cell Display mode, the caller name appears under the number.
  • Allows the Caller ID engine to be changed from In-Cell rows or the live call screen.
  • Lists Auto Redial for busy and no-answer or unreachable calls.
  • Lists Smart Loudspeaker with proximity-driven audio routing and a dual-SIM picker.
  • Includes a local lookup cache and recent-call chat shortcuts for iMessage, WhatsApp, and WhatsApp Business.
  • Lists refinements to recents, the in-call interface, and tab layout, with localization in nine languages.
