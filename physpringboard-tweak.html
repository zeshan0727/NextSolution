Physpringboard 1.9.16: Configurable Physics for SpringBoard Icons

Physpringboard 1.9.16 is a Home Screen tweak by WeWaffles. Its package description says it can shake SpringBoard icons loose with configurable physics on rootless Dopamine. The release is listed for iphoneos-arm64, and the metadata names mobilesubstrate and preferenceloader as dependencies. The release is marked as updated, with version 1.9.14 listed as the previous version. No detailed change log or explicit iOS version is supplied.
