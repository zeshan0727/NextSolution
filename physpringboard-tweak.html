Physpringboard 1.9.19: Configurable Physics for SpringBoard Icons

Physpringboard 1.9.19 is an updated Home Screen tweak by WeWaffles. Its listed function is to shake SpringBoard icons loose using configurable physics on rootless Dopamine. This release is identified for the iphoneos-arm64 architecture and lists mobilesubstrate and preferenceloader as dependencies.
