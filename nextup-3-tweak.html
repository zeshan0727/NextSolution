NextUp 3 Shows and Skips the Upcoming Song from Now Playing

NextUp 3 adds a preview of the song waiting in the queue and a way to skip it before it begins. The current build brings that idea to modern Lock Screen and Control Center media surfaces.

Version1.1
Listed supportiOS 14.2–26.0.1
PriceFree
SourceHavoc

What NextUp 3 actually changes

Instead of opening the music app to inspect the queue, NextUp 3 exposes the next track beside the existing Now Playing controls. If the upcoming song is not wanted, the tweak provides a direct skip action.

The official screenshots show how the extra information fits into different system media surfaces. This is a functional media-control tweak, not merely a restyled player.

  • Preview the upcoming track from the Lock Screen media player.
  • Skip the queued song before it starts.
  • Integrate upcoming-track information with Control Center and supported system media surfaces.
  • Work with the currently listed Apple Music, Apple Podcasts, Spotify and YouTube Music integrations.

Compatibility and requirements

  • Havoc lists iOS 14.2 through iOS 26.0.1.
  • The current listing identifies rootless support.
  • App support is specific; confirm that your media app appears in the current package notes.
  • Another Now Playing replacement can conflict visually or functionally, so test one media tweak at a time.
Important: The older public NextUp repository documents many historical media-app integrations. NextUp 3's current Havoc listing should take priority when deciding which apps and iOS versions are supported today.

Installation checklist

  1. Confirm your iOS version and music app on the official listing.
  2. Install NextUp 3 from Havoc through your normal trusted package manager.
  3. Respring if requested by the package manager.
  4. Start playback in a supported app and open the Lock Screen player.
  5. If the next track does not appear, temporarily disable other media-player tweaks before reporting a problem.

Frequently asked questions

What information does NextUp 3 add?

It shows the next queued track in supported Now Playing interfaces.

Can it skip the next song?

Yes. Skipping an unwanted upcoming track is one of the package's core listed functions.

Which music apps are currently listed?

The public listing includes Apple Music, Apple Podcasts, Spotify and YouTube Music.

Does it support rootless?

The current Havoc listing identifies rootless support.
