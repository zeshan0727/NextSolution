NextUp 3 v1.1 Adds Upcoming-Track Controls to the iOS Now-Playing UI

NextUp 3 is an iOS jailbreak tweak by yves. Version 1.1 displays the upcoming track and provides a way to skip it from the now-playing UI. The package description lists support for Apple Music, Apple Podcasts, YouTube, YouTube Music, and Spotify, with the feature available in the Lock Screen, Control Center, and Dynamic Island. The package includes arm and arm64 release variants.

What the package metadata says it does

  • Shows the upcoming track from the now-playing interface.
  • Provides an option to skip the upcoming track from the now-playing UI.
  • Lists compatibility with Apple Music, Apple Podcasts, YouTube, YouTube Music, and Spotify.
  • Adds the described now-playing interface behavior to the Lock Screen, Control Center, and Dynamic Island.
  • Provides release variants for the iphoneos-arm and iphoneos-arm64 architectures.

Compatibility information

The package metadata lists compatibility with iOS 14.2 - 26 and requires firmware version 14.2 or later, along with ellekit or mobilesubstrate version 0.9.5000 or later, com.opa334.libsandy, and preferenceloader.
