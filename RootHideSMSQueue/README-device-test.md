# Next Ledger SMS Daemon 2.0.1 device test

1. Install the matching Next Ledger TIPA and open it once.
2. Save the **6760, **0023, Cash, and Loan Payment mappings.
3. Install the RootHide daemon DEB.
4. Open Settings > SMS Import Console and verify Installer Diagnostic, Daemon Running, and a fresh heartbeat.
5. Send or receive one new supported CBQ SMS and verify the classification and account mapping before removing the temporary console.
