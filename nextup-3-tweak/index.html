NextUp 3 1.1.1 Adds Upcoming-Track Controls to the Now-Playing Interface

NextUp 3 version 1.1.1 is an iOS media tweak by Yves. Its listed function is to show and skip the upcoming track from the now-playing interface. The package description lists support for Apple Music, Apple Podcasts, YouTube, YouTube Music, and Spotify, with the feature available in the Lock Screen, Control Center, and Dynamic Island on iOS 14.2–26.

Version1.1.1
Architectureiphoneos-arm, iphoneos-arm64
AuthorYves

What NextUp 3 changes

  • Shows the upcoming track from the now-playing interface.
  • Lets users skip the upcoming track from the now-playing interface.
  • Lists compatibility with Apple Music, Apple Podcasts, YouTube, YouTube Music, and Spotify.
  • Adds the described now-playing behavior to the Lock Screen, Control Center, and Dynamic Island.
  • Provides release 1.1.1 for both iphoneos-arm and iphoneos-arm64 package variants.

Compatibility and requirements

The package metadata explicitly lists iOS 14.2–26 and the five supported media apps. Its architectures are iphoneos-arm and iphoneos-arm64. Installation also lists ellekit or mobilesubstrate version 0.9.5000 or later, firmware 14.2 or later, com.opa334.libsandy, and preferenceloader as dependencies.
