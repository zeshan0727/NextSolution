# Next Jailbreak Website App

Native iOS/TrollStore wrapper for **nextjailbreak.com**.

## Tabs

- Home
- Videos
- Tutorials
- Downloads
- Uploads
- FAQ

## Included behavior

- Native back, forward, reload, home, share, and Safari controls
- Pull to refresh and swipe-back navigation
- Website cookies/cache retained between sessions
- YouTube, X, Instagram, Mega, GitHub, email, and custom links open correctly
- File downloads use WebKit download handling and offer **Save to Files**
- Extensionless URL fallbacks for GitHub Pages routes
- Offline/loading error screen with retry
- iPhone and iPad support from iOS 15
