# Next Ledger — App Review Notes

Use this as the basis for App Store Connect → App Review Information → Notes.

Next Ledger is a personal ledger, expense tracking, budgeting and reporting utility for iPhone. No account or sign-in is required to use the app.

Core review path:
1. Launch the app.
2. Add an account from the Accounts tab if desired.
3. Use Home → Quick Add to create an Income or Expense.
4. Use Transfer to move an amount between two locally created accounts.
5. Open Reports to view local summaries and report views.
6. Open Settings → Budgets to configure local category budgets.
7. Settings → Import & Export provides user-initiated CSV/JSON export and import through Apple's system file picker.
8. Optional iCloud Drive backup is controlled by the user in Settings and uses the user's private iCloud container.
9. Apple Shortcuts actions are optional and run only when configured or invoked by the user.

All ledger entries are created or imported by the user. The app does not require a backend account or demo credentials for review.
